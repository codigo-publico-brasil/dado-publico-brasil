Como consultar

O DuckDB lê da internet apenas os trechos de que a consulta precisa. As outras ferramentas leem o Parquet direto por HTTP.

DuckDB

-- conecta ao catálogo e lista as tabelas
ATTACH 'https://datalake.codigopublicobrasil.com.br/catalogo.duckdb' AS cpb (READ_ONLY);
SHOW ALL TABLES;
SELECT * FROM cpb.marts.dim_pessoas LIMIT 10;

Python

import duckdb

con = duckdb.connect()
con.execute("ATTACH 'https://datalake.codigopublicobrasil.com.br/catalogo.duckdb' AS cpb (READ_ONLY)")
df = con.sql("SELECT * FROM cpb.marts.dim_pessoas LIMIT 10").df()

Conferir um arquivo

# compare com o sha256 do manifesto
curl -s https://datalake.codigopublicobrasil.com.br/marts/pessoas/dim_pessoas.parquet   | sha256sum

O caminho sempre aponta para o dado atual. Para citar um número, anote o id_execucao de metadata.exportacao e guarde o resultado.

Organização do lake

Os dados vão da fonte ao resultado em camadas; o que se consome fica em marts.

CaminhoConteúdo
marts/<domínio>/<tabela>.parquetO que se consome, com contrato de colunas (legislativo, eleições, pessoas, território).
staging/ e intermediate/A base tratada de cada fonte e os passos da derivação.
arq_* (pastas de arquivos)Arquivos que não são tabela, cada coleção com sua lista arq_*.parquet: os zips originais do Diário Oficial da União (fonte: Imprensa Nacional, licença CC BY-ND 3.0, sem modificação) e as fotos oficiais dos candidatos (TSE).
metadata/capturas.parquetURL oficial, SHA-256 e data de cada arquivo capturado da fonte.

Limites e avisos

Não estão aqui dados pessoais sensíveis nem documentos pessoais. O projeto é independente e não representa governo, órgão público ou partido. Encontrou um erro ou tem uma dúvida? Abra uma issue no GitHub.
